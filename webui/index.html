📀 Criar a ISO

⚠️ É o disco que será apagado na máquina de destino, não neste computador.

☁️ Gerar no GitHub Actions

O caminho para qualquer máquina sem xorriso (esta, por exemplo). O build roda nos servidores do GitHub e você baixa o arquivo.

  1. Abra Actions → workflow iso.
  2. Clique em Run workflow e escolha os mesmos valores do formulário acima.
  3. Marque air_gapped se quiser a ISO que se basta.
  4. Ao terminar, baixe o artifact e extraia o .zip (dentro está o .iso).
  5. Volte aqui e clique em Conferir na seção de ISOs, apontando o caminho.
Dica: o arquivo baixado do Actions é um .zip. Renomear para .iso não funciona — é preciso extrair.
