# tests/families-matrix.txt — corpus de nomes de CPU reais → família esperada
# -----------------------------------------------------------------------------
# Cada linha:  <família-esperada>|<model name do /proc/cpuinfo>
#
# Para que serve: provar que o casamento CPU → família (families/resolve.sh,
# função pick_family) acerta em dezenas de modelos REAIS. É o máximo de
# validação possível sem possuir o hardware: não prova a ISA nem o -march em
# execução, mas prova a REGRA DE SELEÇÃO — que é justamente onde um regex errado
# mandaria um Ryzen 8000 para o `generic` (já aconteceu, ver docs/FAMILIES.md).
#
# Consumido por tests/test-families.sh (e pelo job 'validate' do CI).
#
# Regras ao adicionar linhas:
#   * use o nome EXATO como aparece em /proc/cpuinfo (com os parênteses);
#   * se o modelo não deve casar com nenhuma família, o esperado é `generic`;
#   * se você mudar um regex em families/, adicione aqui o caso que o motivou.
# -----------------------------------------------------------------------------
